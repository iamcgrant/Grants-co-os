# Mortgage LOS (MORTGAGE_LOS)

Backend module for mortgage loan origination inside Grants & Co OS.

- Service code: `MORTGAGE_LOS`
- API: `/api/los/applications/*` (session auth via `gc_session`)
- Domain: `src/lib/los/*`
- Compliance: `docs/LOS-COMPLIANCE.md`
- Migration handoff: `docs/LOS-MIGRATION.md`

Apply UI and staff desks are not part of this land. Logo: `public/brand/logo.png` via `LosBrandHeader`.
